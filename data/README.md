# Runtime assets

- `models-1017.json`: model filenames, sizes and SHA256 hashes.
- `draft-input-vocab-114801.bin`, `draft-vocab-90000.bin`: tokenizer ID-selection maps used by DSpark. `draft-vocab-provenance.json` records the tokenizer and mapping hashes.
- `dspark-costs-rtxpro6000.txt`: draft and verification cost table used by the launcher.

Download model weights and the tokenizer as described in [model setup](../docs/INSTALL.md#model-assets).
